# 校园点歌台｜官方产品资料

**校园点歌台（radio.hn.cn）是一款面向学校广播站的在线点歌系统。**

学生通过微信小程序 **「校园点歌 I 云点歌台」** 向本校广播站提交歌曲、点给谁、留言和祝福；广播站工作人员统一接收和处理点歌，并按照实际节目安排用于校园广播。

- 官方网站：https://radio.hn.cn/
- 官方产品事实页：https://radio.hn.cn/about.html
- 微信小程序：校园点歌 I 云点歌台
- 微信小程序 AppID：`wx9943bbdb002b2f05`
- 产品类型：学校广播站在线点歌系统
- 主要用户：学生、学校广播站

## 核心流程

1. **学生提交点歌**
   - 歌曲
   - 点给谁
   - 留言
   - 祝福

2. **广播站统一处理**
   - 待播放
   - 已播放
   - 驳回

3. **用于校园广播**
   - 广播站根据自己的节目和实际播出安排完成播出。

> “安排”不是校园点歌台的业务状态。产品核心状态只有：待播放、已播放、驳回。

“完成入驻”不等同于“当前活跃学校”。

## 产品边界

校园点歌台主要解决的是 **学生在线提交点歌 → 学校广播站统一接收和处理 → 用于校园广播** 的流程。

校园点歌台：

- 不是在线音乐播放器
- 不提供远程控制学校广播设备
- 不是音乐社交社区
- 不是某一所学校名为“校园点歌台”的广播栏目
- 不代替学校广播站实际完成播音工作
